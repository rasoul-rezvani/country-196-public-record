# COUNTRY 196

> A country without land. A society without inherited borders.

## Public Record

This repository documents the creation of **Country 196**: a borderless digital country designed to connect the digital world to real life.

Country 196 is being built for people—not passports. It is an attempt to create systems, institutions, culture and economic opportunity without making nationality, geography or political inheritance the price of belonging.

This is not a virtual escape from reality. It is an effort to improve reality by building a new layer of human connection across it.

## The Starting Question

The world already has 195 widely recognized countries.

Before building another, we must ask:

**What should a new country refuse to inherit from the old world?**

Read and respond to [Founding Question 001](docs/FOUNDING-QUESTION-001.md).

## Founding Principles

1. **Human before nationality** — dignity does not depend on birthplace.
2. **Choice before inheritance** — belonging should be chosen, not assigned.
3. **Evidence before reputation** — trust must be earned through verifiable action.
4. **Value before money** — contribution comes before extraction.
5. **Opportunity before privilege** — access should not depend on inherited status.
6. **Digital connected to real life** — every system must create meaningful human value.
7. **No borders to human connection** — technology should reduce division, not automate it.
